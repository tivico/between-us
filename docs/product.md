# 產品核心與範圍

更新日期：2026-10-08。此文件記錄目前已確認方向；「規劃」不代表已實作。

## 一句話

雙人主題測驗平台：選一個想了解的主題，各自回答，雙方完成後一起看結果與彼此選項，把答案變成對話。

## 已確認需求

- 主要給專案持有人、另一半與有伴朋友使用，維持簡單架構。
- 重視好看、清楚、完整的手機與桌面體驗。
- 網站有多個獨立主題，三觀與核心價值為第一個正式測驗。
- 可用於交往前探索，也能用於已交往伴侶；不能把關係階段默認成已婚。
- 遠距指遠距離戀愛：希望補足日常不可見、期待不明與議題未談的理解落差。
- 生育排除目前規劃。
- A 完成後再邀請 B；B 看不到 A 的答案，雙方完成後才一起解鎖。
- 結果包含雙方逐題選項，不只摘要。
- 題目要有可查核學術根據，驗證狀態需透明。
- 初期不設會員，採後端保存回合與答案、每輪私人返回連結，另提供此裝置最近的測驗入口。
- 邀請連結與私人返回連結分開；換裝置可用私人返回連結查看同一輪，裝置紀錄不作為唯一保存來源。
- 感情科普採獨立文章區＋結果短卡的基本分工，具體文章、順序與顯示條件仍待設計。
- 第一份三觀測驗聚焦核心價值與人生方向，兩者分開解讀，正式工具與題數仍待選定。

## 免會員的紀錄保存（方向已確認，尚未實作）

沒有會員不代表不能保存。後端保存已建立回合、暫存與提交答案；私人返回憑證識別各自的參與者。瀏覽器的最近紀錄只提供方便入口，不能代替後端保存與授權。

建議紀錄列表依狀態提供「繼續填答／等待對方／查看結果」。跨裝置使用私人返回連結；清除瀏覽器資料可能失去此裝置的最近入口，但不直接刪除後端紀錄。私人連結也遺失時的找回方式、到期日與刪除權尚未定案，不承諾無會員可自動找回所有歷史。

保存期限、刪除單方答案對共同結果的影響、邀請失效處理需在正式分享前確認。第一版不因紀錄需求預先加入會員；將來有跨裝置完整歷史／找回需求，再另行規劃。

## 感情科普的分工（基本方向已確認，尚未實作）

共同原則已確認：題目、結果解釋與科普都要有能查核的學術依據，不以流行說法或附一篇論文冒充已驗證工具。

以同一份科普內容提供兩種入口，具體呈現仍需設計：

| 位置 | 目的 | 建議內容 |
| --- | --- | --- |
| 獨立「關係小知識」區 | 未做測驗也能依興趣閱讀 | 完整說明、研究對象與方法、支持範圍、討論提案與來源 |
| 測驗結果 | 幫助理解本輪答案 | 短科普卡、為何出現這張卡、一起聊的問題、完整文章連結 |
| 作答前／作答中 | 理解作答方式 | 必要術語與題目目的，不預先顯示針對答案的建議或完整解讀 |

結果頁順序建議為「雙方答案 → 中性整理 → 相關科普 → 討論問題」。沒有驗證的情境題只做答案與期待的描述，不推論人格、依附型態、愛的程度或未來關係。

獨立區與結果區的分工已獲同意；順序是產品設計建議，不是已有研究證明此頁面順序能改善關係。尚未新增導覽或畫面。

## 共用功能與主題內容

共用功能包含主題館、說明、獨立填答、暫存、提交、邀請、等待、解鎖、結果骨架與逐題查看。

各主題自行定義目的、適用情境、面向、題目、答案型態、研究來源與結果規則。共用畫面不代表共用計分公式。名目選項（不同做法的分類）不能因顯示在 A/B/C/D 就當連續分數。

初期題型為單選；未來「重要程度」、「是否聊過」、「補充一句話」需各自定義，不可默默加入既有量表計分。尚未經歷、尚未想清楚、暫不分享是不同狀態，不算相同答案或零分。

### 第一份三觀測驗

定位為「認識彼此心裡重要的事，以及想過的人生」，以核心價值與人生方向為範圍；一般世界／社會信念與具體遠距、金錢、溝通安排另留給其他主題。六個白話概念只協助整理內容，不是核定量表的六個分數。

完整歸納見 [三觀測驗內容藍圖](quizzes/core-values.md)。目前畫面仍是 3 題示例，正式量表、題庫、計分與完成時間待選，不把文件當成已實作功能。

## 正式雙人流程（規劃）

1. A 選定主題、閱讀題目目的與答案分享說明，填寫暱稱並接受。
2. 建立回合，固定題目與結果規則的版本。A 獨立填答，可暫存。
3. A 提交後鎖定答案，獲得 B 的邀請連結與自己的私人返回入口。
4. B 加入、接受分享說明、獨立填答並提交。
5. 後端確認兩人的提交與分享同意，解鎖共同結果。
6. 雙方各自可以查看同一份結果與彼此選項，不要求同時在線。

同時按「準備好了」才揭曉不是第一版必要條件。重新測驗另開回合，不能修改已解鎖回合的答案。若沒有正式同意分享，不應建立可分享答案的回合。

## 結果呈現（規劃）

- 共同重視／偏好的地方。
- 不同想法或期待，以中性語言描述。
- 逐題列出雙方選項與願意分享的補充。
- 題目適用的討論提示；可標記「想一起聊」。
- 有問重要程度／是否聊過時，才可列出「未談過的重要期待」。目前草題沒有這些資料，不能憑空推論。
- 不提供關係成敗預測、愛的程度、心理診斷或未驗證的契合百分比。

## 0.1 基礎建設的完成標準

本機可執行與建置；內容與呈現分離；有可操作的主題館、介紹與作答示例；草題明確標示；手機版與鍵盤可使用；文件描述現況、資料流程、維護方式與後續工作。

## 第一份正式測驗的完成標準（後續）

- 正式題庫及其使用／翻譯條件確認，依據與驗證狀態可查核。
- 接上後端，完成建立、暫存、邀請、B 加入、提交、解鎖與結果。
- A 與 B 兩個獨立瀏覽器／裝置可完整使用；解鎖前無法讀到對方答案。
- 提交重試、邀請重用、連結失效、網路中斷、資料刪除都有明確行為。
- 測試結果規則；正式的計分方法不能由示例選項 ID 推測。
