# 題目、依據與驗證

## 目前狀態

正式題庫尚未完成。三觀的 3 題是自編介面示例；可以幫忙討論題型，但不是 PVQ 原題、已驗證中文版、正式三觀量表或關係預測工具。遠距主題只有研究方向；其餘主題尚待研究。

第一份三觀的範圍已確認為核心價值＋人生方向，詳見 [內容藍圖](quizzes/core-values.md)。人生目標的候選來源為 [Grouzet 等人，2005](https://pubmed.ncbi.nlm.nih.gov/16351369/)，尚未選定工具或中文版本，不把它與價值量表混成一個分數。

## 每題的依據紀錄

`src/content/quizzes.ts` 中：

- `dimension`：想探索的面向。
- `evidence.status`：`research-informed`（依研究方向設計、未完成本工具驗證）或 `validated`（確有對應版本的驗證證據）。
- `sourceIds`：連到此主題 `sources` 的來源。
- `note`：來源支持什麼、此題做了什麼改寫、不能推論什麼。

把 `status` 改成 `validated` 不會使題目真的經過驗證；正式標示必須有文件、專業審查與對應證據。程式檢查只能指出遺失參照／錯誤欄位。

## 三觀契合度的證據與計算邊界

使用者已同意「三觀契合度」作為結果總覽名稱，意義為本輪價值取向的相近程度。核心價值同頻度與人生方向交集分開；正式量表與比較公式尚未選定，現在沒有分數程式。

伴侶相似性研究可作為比較方法的查找方向，不能直接提供本產品的個人契合百分比：

| 來源 | 已查閱的摘要內容 | 本產品的限制 |
| --- | --- | --- |
| [Gaunt, 2006](https://onlinelibrary.wiley.com/doi/10.1111/j.1467-6494.2006.00414.x) | 248 對已婚伴侶，研究相似性與婚姻滿意度／情感的關聯；不同面向與相似性計算方法有不同結果 | 不代表交往前適配，也未驗證此網站的 0–100 指標 |
| [Leikas et al., 2018](https://researchportal.helsinki.fi/en/publications/relationship-satisfaction-and-similarity-of-personality-traits-pe/) | 624 名、312 對異性伴侶的研究；以反應曲面分析比較相似性，部分政治態度與自主價值的相似性和滿意度有關，其他面向結果不同 | 不是三觀總分或關係成功率公式；結果受研究人群與方法限制 |

本輪依先前討論已查閱的公開摘要記錄上述來源，全文與完整方法審查尚未完成。反應曲面分析是一種分析「雙方各自水準與相似／不同組合」的統計方法，並非給每對伴侶的契合度計分表。

選定工具後需另做：核對原計分、比較絕對程度與相對順序的含義、處理反應風格／缺答、核對是否適用個人層次的比較。不以相關係數乘 100、相同選項比例或任意加權直接宣稱已驗證契合度。

如採產品自訂指標，需說明它是可重現的描述性比較與其驗證狀態。數字轉換成 0–100 不會自然增加效度。趣味分段、標題與文字也屬規則，不能以科學口吻宣稱未經驗證的門檻。

## 問題怎麼寫

1. 一題只問一個重點；回覆快不快與有沒有被理解分開。
2. 「我實際怎麼做」與「我希望對方怎麼做」分開，必要時使用配對題。
3. 實際行為用明確時間窗；沒有經歷該情境的人應有可用選項。
4. 選項描述不同取捨，不以明顯道德好壞引導回答。
5. 重要程度、是否聊過、可協商程度不同，不用同一題混問。
6. 不預設性別、異性關係、婚姻或同居；生育不在本版範圍。
7. 既有量表保留核定作答與計分方式，不任意改成 A/B/C/D。

例如遠距「需要獨處」可分成本人習慣、對伴侶期待，再問期待的重要程度。這是產品設計假設，尚不是已驗證題組。若採用這種形式，需實際訪談確認選項可理解、可涵蓋不同生活條件。

## 正式題庫的工作順序

1. 定義要測的概念與適用人群，避免把生活偏好都叫價值觀。
2. 選工具／研究，核對原題、版本、翻譯與使用條件。
3. 為自編或改寫題紀錄依據與變更；尋求相關專業人員審查。
4. 目標使用者試答並口述理解（認知訪談），找出題幹誤解與遺漏選項。
5. 小規模試用，評估完成負擔、敏感性及討論提示是否合適。
6. 若主張量表分數，依測量設計蒐集並分析信度（測量一致性）與效度（是否測到想測的概念），不用少量朋友試玩冒充完整驗證。
7. 若宣稱「增加彼此了解」，另外設計效果評估；不是有文獻就已證明產品有效。

## 科普內容的證據規範

使用者重視學術佐證，適用於題目、結果文字與獨立科普。獨立科普與結果短卡的基本分工已確認，具體文章與顯示條件尚待設計；以下是內容製作與審查規範，不代表文章或介面已上線。

### 三種證據不能混用

1. **研究發現**：原文在什麼對象、方法與條件下發現什麼，包含不顯著或互相矛盾的結果。
2. **測量證據**：本題／量表版本是否真的能測到該概念；理論支持不等於自編題的信效度。
3. **應用與練習**：從研究提出的生活解釋或討論問題，標示為編輯提案。若聲稱練習有實證效果，需找到真正評估該做法的研究，不能沿用概念研究代替。

### 每篇文章／每項主張的紀錄

| 欄位 | 要回答的問題 |
| --- | --- |
| 主張與原文位置 | 這句話由哪篇論文的摘要／段落／表格支持？ |
| 來源 | 作者、年份、完整標題、期刊、DOI／原文連結 |
| 研究方法 | 橫斷問卷、日記、追蹤、實驗、系統性回顧或統合分析？ |
| 對象與情境 | 樣本數、年齡、文化、交往／婚姻、是否遠距；不可默認適用台灣所有伴侶 |
| 支持範圍 | 能說什麼、不能推論什麼，有沒有相反或限制結果？ |
| 編輯應用 | 哪段是白話轉述、設計推論或自編練習？ |
| 審查紀錄 | 查核日期、查閱摘要或全文、審查狀態與文章版本 |

介面可先呈現白話短說明，讓使用者展開「研究怎麼說／限制／來源」。不能只顯示「科學證實」標章、期刊影響因子或模糊的「研究指出」。

### 選文與措辭

- 以原始論文查核具體結果；對廣泛共識另查系統性回顧／統合分析與不同研究，不依一篇論文宣稱普遍定律。
- 優先適用於目標族群的研究，不只挑選支持想法的論文；記錄限制、相反與不顯著結果。
- 觀察性研究以「有關聯／在此樣本觀察到」描述，不改寫成「必然造成」；實驗也須限制到其評估條件。
- 用來源支持到的強度表達，不為了有吸引力創造最佳聊天次數、愛的分數或個人人格結論。
- 原文可公開閱讀不等於可任意複製量表、圖表與文章；引用／改寫條件另核對，主要使用原創白話摘要。
- 題目與科普共用來源識別可減少重複，但文章、題目、結果規則各有獨立版本與審查狀態。

### 可作首批文章的方向（候選，待選）

| 候選主題 | 可用來源與已查核內容 | 邊界 |
| --- | --- | --- |
| 價值觀比較的是重視順序 | [Schwartz, 2012](https://scholarworks.gvsu.edu/orpc/vol2/iss1/11/) 的基本價值理論 | 不用單一自編題決定價值分數或伴侶適配 |
| 遠距中的聯絡與回應性 | [Holtzman et al., 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8669216/)：647 名 18–25 歲、在加拿大就學的交往／約會者；遠距組文字聯絡頻率與感受到的回應性和滿意度有關聯 | 橫斷研究；不能訂出最佳聯絡頻率，也不能直接推論因果 |
| 表達壓力與被回應的感受 | [Pagani et al., 2019](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.00401/full)：55 對已婚伴侶的日記資料；明確表達壓力與回應性有關，與滿意度的直接關聯未獲支持 | 不是交往前／遠距特定研究，不能說「把話說清楚一定更幸福」 |
| 遠距中的分享與理想化 | [Jiang & Hancock, 2013](https://academic.oup.com/joc/article-abstract/63/3/556/4086003) | 不把理想化直接當成欺騙，也不假定每對遠距伴侶都不了解彼此 |

本次追加查核日期為 2026-10-08。Holtzman 一文查閱公開全文的摘要與方法段；Pagani 一文查閱公開摘要與概念段，全文審查尚未完成。以上為候選內容的證據筆記，不是已驗證題庫或已核定科普稿。

### 結果短卡的草案示例

假設一方想先被聽見，另一方習慣提供做法，結果先忠實列出選項，再提供「回應性：感到被理解與關心」的相關概念。討論提案可寫：「下次分享煩惱時，要不要先問彼此現在希望被聽見，還是一起想辦法？」

這段是自編討論提案，尚無此特定提問做法在本產品中的效果驗證。不能依兩題差異就判定對方缺乏同理心，或聲稱這個提示必然提升滿意度。Pagani 的研究也未驗證「先傾聽 vs. 提供解方」這個題組；文章關聯需明確列出此限制。

## 發布與版本

`QuizDefinition.status`：`planned`（方向規劃）、`draft`（內容草案／可預覽）、`ready`（正式開放）。現在沒有 `ready` 主題。

正式開放需同時完成內容審查與雙人後端；不能只改狀態標籤。題目或結果規則變更需更新版本，既有回合使用不可變的原版本／快照。尚未選定的量表、題數、計分不能在介面中宣稱已確定。
