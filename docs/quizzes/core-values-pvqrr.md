## 本次選用方向與取捨

優先評估 **PVQ-RR，57 題**。它用人物描述詢問「這個人有多像自己」，涵蓋 19 個較細的價值概念；每個概念對應三題。使用者接受完整工具的負擔，因此保留完整題數、原序、選項與計分對應，人物稱呼改成不限定性別的「這個人」。這是措辭改寫，不是自編伴侶短版；原文留作比對。PVQ40 的繁體工具仍是負擔較低的備選，尚未逐份取得／核對。

依據是 [Schwartz & Cieciuch（2022；2021 年先行公開）](https://doi.org/10.1177/1073191121998760) 的 Measurement Instrument、Table 2 與 Discussion。該研究分析 49 個文化群體、53,472 人；Table 2 有中國與香港，未列 Taiwan。跨文化證據不能直接稱為台灣伴侶版本已驗證，也沒有證明本網站的伴侶契合指標有效。

### 中性措辭的研究先例與邊界

[Mifsud & Sammut（2023），Worldviews and the role of social values that underlie them](https://doi.org/10.1371/journal.pone.0288451) 的 Social values 方法段說明，該研究以英文 they/their 代替按性別配對的人物代名詞。這支持「已有研究採中性稱呼施測」的查核結果；它同時採五段量尺，不能當成本產品保留六段量尺的繁體改寫版之等同性驗證。我們沒有沿用其五段量尺。

「歡迎所有性向／性別認同使用」是產品使用規則；「不同族群的測量表現等同」是另外要驗證的研究主張。這篇研究沒有提供我們的繁體措辭、台灣伴侶或全性向伴侶比較驗證。正式介紹應標示「依 PVQ-RR 改寫的性別中性措辭版本」，不宣稱原作者已核定本版或本產品已完成全性向測量驗證。

完成時間需要實際繁體手機試答，現在不承諾幾分鐘。分頁、進度、暫存可以沿用既有介面，正式版仍要檢查 57 題負擔與長選項的手機排版。

## 計分與結果規格候選

19 個概念的題號已從作者計分文件整理到 JSON 的 `values[].itemNumbers`，全部 57 個題號恰好各出現一次。保留此對應，不用 UI 的白話六類改成六個新分數。

作者文件區分原始程度與個人相對重視程度。完整作答時，先對每個概念的三題取平均，再算全部 57 題的個人平均 MRAT；概念平均減 MRAT，是相對於這個人自己整體作答的重視程度。負數不代表壞價值或「不重視」。不同統計分析有不同規則，不能把個人中心化當所有分析通用的步驟。

本產品暫以個人價值整理與逐題並排為候選呈現，**沒有實作分數**。同頻度另需設計；不把 19 個概念直接相加、不把相關係數乘 100、不任意設「非常契合」門檻。原工具的單人測量證據也不能直接變成雙人的戀愛成功率。

暫不實作 10 類／4 大類合併。作者這份計分文件的 10 類 Tradition 包含 Humility 的三題，論文正文描述合併時的表達與此不完全相同；若要採較粗分類，需核對最新計分版本與合併目的。19 類可先忠實保留，Face／Humility 不憑直覺塞入大類。

結果文字樣稿（格式提案，非實際使用者結果）：

> 你們在這一輪對自主思考的重視順序有所不同。下方列出各自的原選項，可以聊聊：做重要決定時，你希望保留哪些自己思考的空間？

此句只有在相對重視程度、排序與差異規則核定後才能使用；討論問句為自編編輯提案，未驗證效果。更保守的第一步是「A 選：[原選項]；B 選：[原選項]」，先忠實提供答案，不生成性格評價。

## 人生方向區塊的處理

第一份主題仍保留「核心價值＋人生方向」的定位；這次完成的是核心價值候選資料。人生方向也優先評估既有工具，不偷偷換成少量自編題後沿用量表名稱。

[CSDT 的 Aspirations Index 官方說明](https://selfdeterminationtheory.org/aspirations-index/) 列七類、每類五個目標，另外分別詢問重要程度、達成可能與已達成程度；完整包標示 105-item。[Grouzet 等人（2005）](https://selfdeterminationtheory.org/wp-content/uploads/2014/04/2005_Grouzetetal_StructureofGoalContents.pdf) 的方法段則是 57 個目標、11 類、1–9 的重要程度評分。兩者不是同一版本，不能混稱 35／57／105 題，或只抽幾題便沿用驗證結果。

Grouzet 的 Table 1 與方法支持比較不同目標內容；分析保留 1,854 名大學生。該樣本與工具不能直接代表台灣伴侶或對關係適配的測量。人生目標不與 PVQ-RR 相加成三觀總分。

[官方條款第 1 節](https://selfdeterminationtheory.org/terms-and-conditions/) 對非營利研究用途與線上公開另有條件；免費朋友試玩不自動符合研究用途。若選用該站工具，需確認本網站展示、公開原始碼與翻譯的適用授權；尚未接受下載條款、登記信箱或寄信申請。現階段不用另一個資料庫的 CC0 覆蓋 AI 的條件。

方法方向參考 [CDC／NCHS 的認知訪談說明](https://www.cdc.gov/nchs/ccqder/question-evaluation/cognitive-interviewing.html)：了解受訪者如何理解題目並形成回答。以下人數、流程及記錄格式是本專案的試讀提案，不是該機構驗證過的 PVQ-RR 施測程序。

**第一輪怎麼做**

1. 先邀 3–5 位願意閱讀繁體中文的成年人，個別試讀；人數是小型專案的起始安排，不是效度門檻。讓不同關係階段、性向與性別認同的人知道都歡迎參與，不要求登記性向／性別；只找朋友與少量試讀不能代表涵蓋所有族群。
2. 告知這次在找題目難懂的地方，沒有好壞答案；可以不回答、不解釋私人經驗或停止。這次不是雙人揭曉，不要求將試讀答案交給伴侶。
3. 先讓對方獨立閱讀並試答 `0.2.0` 中性措辭的 57 題與六段原選項，答案可由本人保留，不按性別選原文版。記錄自行完成所需時間、重讀／停頓、未答題與原因；不將訪談追問時間當作測驗完成時間。若只試讀部分，明確標記未涵蓋哪些題。
4. 回頭追問優先題及任何主動指出的困惑。可問：「用你的話，這題在問什麼？」、「選答案時你主要想到什麼？」、「哪個字或選項最難決定？」這些是本專案自編的訪談提示。
5. 不先提供英文、概念分類或第 49 題的預期意思，再聲稱對方自然理解正確。若已有提示，記錄提示內容及發生時間；已讀過本稿疑點的人不能當成完全未受提示的試讀者。
6. 整理各人的理解與困難，再比較是否有共同模式。單一回饋也可以揭露問題；不把「多數看懂」當成允許覆蓋少數理解差異的統計門檻。

試讀後仍有概念差異時，狀態保持「待審」，並請具測驗翻譯／心理計量經驗的人協助評估。試讀能處理可理解性；要主張本地中文版測量效度或雙人契合指標有效，需要另外的研究設計，不能靠這輪少量試讀推論。

## 維護、資料流程與排查

0.5.0 的實際試讀流程是「候選 JSON → `createCoreValuesTrial()` 取 `prompt`／引導／六選項 → `ContentTrial` → 本頁 React state → `summarizeTrial()` 整理本人選項／未答／標記」。題庫在建置時匯入；試答不呼叫 API、不寫 localStorage 或資料庫。離開該元件、關閉或重新整理即清除；同頁返回修改保留選擇。

入口為主題介紹中的「試讀 57 題核心價值」，或 `#/trial/core-values`。作答與整理不顯示價值面向／逐題解釋或第 49 題的已知預期意思，避免在提前查看整理後影響尚未閱讀的題目。具體審查問題留在本文件，試讀者若已讀過也需記錄提示接觸情況。跳過是未答狀態，不是第七個量表選項或零分；可以在任一題查看目前整理。

正式雙人接入時預計由候選資料的 `prompt` 與 `instructions` 建立 `src/content/quizzes.ts` 的工具定義，並補上題目數值、改寫紀錄與施測版本契約；不根據性別選 `portraits`。建立回合時由 Node 或 D1 store 固定內容及規則快照。兩人答案都提交後，先依原工具計分，再按另行核定的比較規則形成結果；性別／性向不參與計算。這是後續規劃，現在沒有新增計分程式。

維護者可依這個順序排查：

1. **畫面只有三題**：`#/demo/core-values`／`#/start/core-values` 仍是三題流程示例；57 題入口是 `#/trial/core-values`，看 `core-values-trial.ts` 是否使用最新候選 JSON。正式雙人接入尚未完成，不能只改 `ready` 標籤。
2. **少題或分類錯誤**：看 JSON `sourceItemNumber` 是否是 1–57，`values[].itemNumbers` 是否無遺漏、重複且每類三題，再核對作者計分表。
3. **中文與英文不一致**：先分辨在看改寫 `prompt` 還是來源 `portraits`，再對照檔名、SHA-256、題號與 `adaptation`；查是否混用 Taiwan／revised 或抄入頁首。原文不覆寫，改寫問題另列。
4. **分數差異異常**：後續先核對選項 ID→數值、原始平均、MRAT、缺答、比較版本；不同人全選高程度不代表較有價值觀。
5. **來源讀不到**：GVSU 403／OSF 匿名 401 不代表工具不存在；從論文作者提供的入口查閱，不猜下載網址或改用來路不明的題單。
6. **仍顯示男性／女性版，或看到「其這個人」**：後續接入時先查作答是否讀 `prompt`，再查是否以性別選 `portraits` 或在畫面即時做字串全域替換。使用審閱好的完整 `prompt`，不讓呈現層自己生成措辭。

日後改題範例：若要把第 49 題改成更自然的中文，先保留此原文基準，另記候選改寫、理由與審查，不能覆寫來源後還稱「逐字採用」。如果只修改結果頁的白話概念標籤，原題與原計分不隨之改動；已發布的結果文字／規則仍要按版本記錄。

可在專案根目錄用唯讀指令檢查數量：

```powershell
$taskBank = Get-Content docs/quizzes/core-values-pvqrr.json -Raw -Encoding utf8 | ConvertFrom-Json
$taskBank.items.Count                      # 應為 57
$taskBank.values.Count                     # 應為 19
```

`items[].prompt` 是共用中性改寫題幹；`portraits` 保存兩套原文；`adaptation` 記錄改寫範圍與證據限制；`instructions` 是候選數位引導。`responseOptions` 的數值來自原工具；`values` 是計分對應；`sourceFiles` 用於確認來源版本；`reviewFlags` 記錄尚待審查的問題。這些診斷只檢查資料形狀，不能證明改寫或翻譯有效。
