## 本次選用方向與取捨

## 計分與結果規格候選

19 個概念的題號已從作者計分文件整理到 JSON 的 `values[].itemNumbers`，全部 57 個題號恰好各出現一次。保留此對應，不用 UI 的白話六類改成六個新分數。

作者文件區分原始程度與個人相對重視程度。完整作答時，先對每個概念的三題取平均，再算全部 57 題的個人平均 MRAT；概念平均減 MRAT，是相對於這個人自己整體作答的重視程度。負數不代表壞價值或「不重視」。不同統計分析有不同規則，不能把個人中心化當所有分析通用的步驟。

本產品暫以個人價值整理與逐題並排為候選呈現，**沒有實作分數**。同頻度另需設計；不把 19 個概念直接相加、不把相關係數乘 100、不任意設「非常契合」門檻。原工具的單人測量證據也不能直接變成雙人的戀愛成功率。

暫不實作 10 類／4 大類合併。作者這份計分文件的 10 類 Tradition 包含 Humility 的三題，論文正文描述合併時的表達與此不完全相同；若要採較粗分類，需核對最新計分版本與合併目的。19 類可先忠實保留，Face／Humility 不憑直覺塞入大類。

結果文字樣稿（格式提案，非實際使用者結果）：

> 你們在這一輪對自主思考的重視順序有所不同。下方列出各自的原選項，可以聊聊：做重要決定時，你希望保留哪些自己思考的空間？

此句只有在相對重視程度、排序與差異規則核定後才能使用；討論問句為自編編輯提案，未驗證效果。更保守的第一步是「A 選：[原選項]；B 選：[原選項]」，先忠實提供答案，不生成性格評價。

## 人生方向區塊的處理

第一份主題仍保留「核心價值＋人生方向」的定位；這次完成的是核心價值候選資料。人生方向也優先評估既有工具，不偷偷換成少量自編題後沿用量表名稱。

[CSDT 的 Aspirations Index 官方說明](https://selfdeterminationtheory.org/aspirations-index/) 列七類、每類五個目標，另外分別詢問重要程度、達成可能與已達成程度；完整包標示 105-item。[Grouzet 等人（2005）](https://selfdeterminationtheory.org/wp-content/uploads/2014/04/2005_Grouzetetal_StructureofGoalContents.pdf) 的方法段則是 57 個目標、11 類、1–9 的重要程度評分。兩者不是同一版本，不能混稱 35／57／105 題，或只抽幾題便沿用驗證結果。

Grouzet 的 Table 1 與方法支持比較不同目標內容；分析保留 1,854 名大學生。該樣本與工具不能直接代表台灣伴侶或對關係適配的測量。人生目標不與 PVQ-RR 相加成三觀總分。

[官方條款第 1 節](https://selfdeterminationtheory.org/terms-and-conditions/) 對非營利研究用途與線上公開另有條件；免費朋友試玩不自動符合研究用途。若選用該站工具，需確認本網站展示、公開原始碼與翻譯的適用授權；尚未接受下載條款、登記信箱或寄信申請。現階段不用另一個資料庫的 CC0 覆蓋 AI 的條件。

## 維護、資料流程與排查

本次屬於內容準備，沒有新的 HTTP 請求。工作流程是「作者原檔 → 原文轉錄／英文對照 → 候選 JSON 與閱讀稿 → 內容審查 → 後續正式接入」。這份 JSON 不是 `QuizDefinition`，不會因新增文件就出現在網站。

正式接入時預計由候選資料建立 `src/content/quizzes.ts` 的工具定義，並補上題目數值與施測版本契約；建立回合時由 Node 或 D1 store 固定內容及規則快照。兩人答案都提交後，先依原工具計分，再按另行核定的比較規則形成結果。這是接入規劃，現在沒有新增計分程式。

維護者可依這個順序排查：

1. **畫面只有三題**：是目前正常狀態，先查 `src/content/quizzes.ts` 是否正式導入，不能只改文件或 `ready` 標籤。
2. **少題或分類錯誤**：看 JSON `sourceItemNumber` 是否是 1–57，`values[].itemNumbers` 是否無遺漏、重複且每類三題，再核對作者計分表。
3. **中文與英文不一致**：對照來源檔名、SHA-256 與題號，查是否混用 Taiwan／revised，或抄入文字方塊的頁首。保持原文，另記審查問題。
4. **分數差異異常**：後續先核對選項 ID→數值、原始平均、MRAT、缺答、比較版本；不同人全選高程度不代表較有價值觀。
5. **來源讀不到**：GVSU 403／OSF 匿名 401 不代表工具不存在；從論文作者提供的入口查閱，不猜下載網址或改用來路不明的題單。

日後改題範例：若要把第 49 題改成更自然的中文，先保留此原文基準，另記候選改寫、理由與審查，不能覆寫來源後還稱「逐字採用」。如果只修改結果頁的白話概念標籤，原題與原計分不隨之改動；已發布的結果文字／規則仍要按版本記錄。

可在專案根目錄用唯讀指令檢查數量：

```powershell
$taskBank = Get-Content docs/quizzes/core-values-pvqrr.json -Raw -Encoding utf8 | ConvertFrom-Json
$taskBank.items.Count                      # 應為 57
$taskBank.values.Count                     # 應為 19
$taskBank.responseOptions.Count            # 應為 6
($taskBank.values.itemNumbers | Sort-Object -Unique).Count  # 應為 57
$taskBank.values.itemNumbers | Group-Object | Where-Object Count -ne 1  # 應無輸出
```

`items` 是原題；`portraits` 保存兩套原文；`responseOptions` 的數值來自原工具；`values` 是計分對應；`sourceFiles` 用於確認來源版本；`reviewFlags` 記錄尚待審查的問題。這些診斷只檢查資料形狀，不能證明題目翻譯有效，也不能代替逐題比對原檔。

本次驗證為來源轉錄、數量、題號、選項、計分覆蓋與閱讀稿一致性。沒有新增量表效度證據、受試者訪談、計分程式或雲端發布；網站／題庫版號不升版。
