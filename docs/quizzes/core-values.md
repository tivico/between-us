# 三觀探索：核心價值與人生方向

更新日期：2026-10-08。文件狀態：已確認範圍的內容藍圖。0.4 已上線三題示例的雙人流程；正式工具尚待核定。使用者已選擇優先完整既有量表，接受較多題目；本次已建立 [PVQ-RR 57 題候選稿](core-values-pvqrr.md)，尚未導入網站。

## 1. 一句話定位

認識彼此心裡重要的事，以及想過的人生。兩人各自回答，完成後一起看各自的重視順序、目標與逐題答案，把差異變成可以討論的事情。

對外名稱可使用「三觀探索」，副標題明確寫「核心價值與人生方向」。第一版不宣稱完整測量世界觀、人生觀、價值觀的所有內容。

## 2. 目的與適用情境

- 交往前、曖昧／約會中的兩個人：了解各自想法，不預設已建立共同生活規則。
- 交往中的伴侶：重新理解彼此重視的事與人生方向。
- 遠距伴侶也可使用本主題，但遠距聯絡與見面安排由獨立遠距測驗處理。

使用者完成後應能描述「我重視什麼、對方重視什麼、我們想往哪裡走、哪些地方值得再問」，不是由網站代替兩人決定是否交往。

## 3. 內容分成兩個區塊

### A. 核心價值：什麼對我重要？

探索可跨不同生活情境的重視方向，例如自主、安全、探索、成就、關懷與公平等。依核定的價值工具呈現個人取向，不把不同生活情境的單題當成完整心理概念。

### B. 人生方向：我希望把人生投入哪裡？

探索希望追求的目標與投入方向，例如個人成長、親密關係、經濟目標、生活享受或對社會的貢獻。具體分類須依後續選定的目標研究與工具核對。

兩個區塊分開解讀，不合成任意的「三觀總分」。價值、人生目標、生活條件與實際行為也不能互相替代。

## 4. 六個白話內容概念

以下延續已討論的概念，用來整理內容與閱讀方式，**不是新建立或已驗證的六面向量表**。

| 區塊 | 內容概念 | 想了解什麼 |
| --- | --- | --- |
| 核心價值 | 自主 | 自己做決定、保留選擇權有多重要？ |
| 核心價值 | 安全與穩定 | 多重視生活保障、可預期與安定？ |
| 核心價值 | 探索與改變 | 多重視新經驗、挑戰與嘗試？ |
| 核心價值 | 成就 | 達成目標、發揮能力有多重要？ |
| 核心價值 | 關懷與公平 | 如何重視親近的人，以及更廣泛的人與環境？ |
| 人生方向 | 人生目標 | 希望把時間、心力與資源投入哪些方向？ |

採既有量表時，正式題數、面向與計分必須遵循該工具，不能只保留此表列的部分就聲稱沿用原工具效度。這張表不代表其他價值不重要，亦不代表每人只能選一種價值。

## 5. 範圍邊界

| 內容 | 第一份怎麼處理 |
| --- | --- |
| 核心價值與人生目標 | 主要範圍，區分兩個區塊 |
| 工作、休閒、幫忙等生活情境 | 可作理解價值取捨的討論題，須記錄來源／設計假設 |
| 一般社會／世界信念 | 不納入第一版核心測量；未來可另開主題 |
| 聯絡頻率、忙碌回應、見面安排 | 留給遠距主題 |
| 約會費用、儲蓄、共同支出 | 留給金錢與生活主題；經濟人生目標仍可在本測驗討論 |
| 爭執、冷靜、修復方式 | 留給溝通與衝突主題 |
| 相處時間、獨處、資訊分享 | 留給陪伴與界線主題 |
| 生育 | 排除目前規劃 |
| 人格、依附型態、心理診斷 | 不是本測驗測量目標，不從這份答案推斷 |

判斷方式：問「為何重視」可能屬於本測驗；問「兩人具體怎麼安排」通常屬於其他主題。例如希望經濟獨立是人生目標，約會帳單怎麼分攤則是具體關係期待。不能只按題目提到金錢就歸在同一個分數。

## 7. 題型與作答原則

- 優先選用適合的既有測量工具，再決定介面；單選的形式可以是程度選項，不一定是情境 A/B/C/D。
- 量表保留核定的題幹、作答、缺答與計分規則；若要改寫或刪題，需重新標示與評估。
- 自編情境題作為理解取捨的討論延伸，與正式測量結果分開，不把選項次序換成分數。
- 不暗示哪個選項較體貼、成熟或正確。
- 理想、實際行為與對伴侶期待分開；行為題設定時間範圍，不把近期疲累直接解釋成不重視成就。
- 尚未經歷、尚未想清楚與暫不分享有不同意義；是否提供、能否跳題與計分處理，依工具及分享規則另定。
- 重要程度、是否聊過、補充理由列為候選欄位，不在尚未核定前強制加入或計分。

## 8. 結果內容與解讀邊界

正式結果預計包含：

1. 「三觀契合度」總覽卡，作為揭曉入口；定義為本輪價值取向的相近程度，不是戀愛成功率。
2. 核心價值同頻度與各自的價值整理（依核定工具才可生成分數／排序）。
3. 人生方向交集與各自的投入方向（另依目標工具或清楚標示的探索題），與核心價值分開解讀。
4. 共同重視的事與不同取向，忠實依兩人資料描述。
5. 逐題並排的選項與願意分享的補充。
6. 相關科普、為何出現該說明、討論提示與延伸閱讀。

自編情境題在未驗證時只描述選擇，不生成量表分數。沒有詢問重要程度或是否聊過，就不能自動列「尚未談過的重大衝突」。價值差異不直接代表衝突，同樣的選項也可能有不同原因。

不提供沒有計算依據的契合百分比、愛的程度、對錯評判、心理診斷、是否適合結婚或關係成敗預測。不合併人生目標與價值為任意總分。

### 三觀契合度的趣味呈現（方向已確認，公式與畫面尚未實作）

使用者同意以「三觀契合度」作為結果頁的揭曉亮點。保留吸引人的總覽卡、揭曉動畫與向下展開的設計，詳細答案與科普仍是理解依據。動畫需支援減少動態效果偏好。

| 顯示內容 | 定義與限制 |
| --- | --- |
| 三觀契合度總覽 | 以本輪價值取向相近程度為主要意義；卡片可整理兩個區塊，但不要求任意合成單一分數 |
| 核心價值同頻度 | 比較核定工具所得的價值重視程度／排序；具體比較方法待選 |
| 人生方向交集 | 顯示共同追求的目標與不同方向；不直接加進價值同頻度 |
| 值得聊的差異 | 中性列出相異答案與討論提示；不能直接命名為衝突或不適合 |

是否顯示 0–100、以何種比較方式呈現、如何處理缺答、相同分數與結果語句，以及是否有足夠證據設定分段，須在量表／題庫選定後另外核定。現在沒有公式、權重、門檻或範例數字；不以文獻中「相似性有關聯」直接生成個人百分比。

如將來採數字指標，結果需能展開「分數怎麼算」，說明使用的資料、比較方法、涵蓋範圍、缺答處理與驗證狀態。保留比較規則的版本，舊回合可重現。趣味標題與揭曉效果不能使使用者誤認為數字是關係成功率或百分位排名。

預計呈現流程為「契合度總覽 → 各區塊與差異 → 逐題答案 → 相關科普與討論」。這是產品呈現規劃，不是已驗證的介入效果。

## 9. 科普與討論

已同意獨立科普＋結果短卡的基本分工；文章與顯示條件仍待內容設計。

首批可優先討論的文章方向（標題草案，非已核定文稿）：

- 「價值觀：哪些事對我更重要？」
- 「價值、人生目標與日常習慣有什麼不同？」
- 「重視自由，也能同時重視穩定嗎？」

文章各自查核來源，結果先顯示答案與中性整理，再提供相關短卡、討論問題與完整文章。作答前只提供必要概念說明，不先展示針對答案的建議。

自編討論提示示例：「你選擇穩定時，最想保護的是收入、生活節奏，還是其他事情？」不能因這句提示與研究概念相關，就宣稱其效果已被驗證。

## 10. 使用流程（0.4 已部署，正式題庫待核定）

```text
選三觀主題 → 目的／分享說明 → A 獨立填答並提交
  → A 保存私人返回連結、傳 B 邀請連結
  → B 接受分享說明、獨立填答並提交
  → 後端確認雙方完成與同意 → 解鎖結果與雙方逐題答案
```

使用免會員的後端保存；每輪固定題庫與結果規則版本。重測另開回合，已提交答案不在本輪修改。期限、刪除與遺失憑證找回規則仍待定。

使用者選擇優先既有量表後，第一批成果為 [PVQ-RR 候選 JSON](core-values-pvqrr.json) 與 [完整閱讀／查核稿](core-values-pvqrr.md)。候選內容自己的版本是 `0.1.0`，與目前三題示例的 `QuizDefinition.version` 分開；JSON 不被程式載入。接下來先比較中文版本與處理審查問題，再完成結果、人生方向工具與正式接入。

後續依序：

1. 比較候選工具的目的、中文版本、使用條件、題數與完成負擔。
2. 確定核心價值及人生目標是否各採既有工具，或人生目標先做清楚標示的探索題。

4. 寫結果樣稿與相關科普，再用不同假設答案檢查不越界解讀；同時比較同頻指標的候選方法，不以任意平均、名目選項順序或直覺門檻生成分數。
5. 目標使用者試答、內容審查；需要主張測量效度時另做必要驗證。

## 12. 維護與內容除錯

- 想增刪範圍：先更新本文件與產品文件，再調整相關研究對應；沒有原文支持的面向保持候選狀態。
- 想審閱正式候選題目：先看 `core-values-pvqrr.md` 的完整原題與問題；候選資料在同名 JSON。目前仍未導入。正式工具確定後，再修改 `src/content/quizzes.ts` 並依 `docs/runbook.md` 驗證；題目與結果規則變更需建立新版本，不改舊回合快照。
- 結果看起來像人格判定、道德分數或戀愛成功率：先核對本文件第 8 節，再回查題目概念、原計分、相近程度的計算規則與科普主張，不靠換句話掩蓋無法支持的推論。
- 日後出現同一輪分數不一致：依序比對題庫版本、雙方答案／缺答、量表計分、比較規則版本與輸出；不能用畫面硬改數字。現在尚無計分程式，這是後續排查順序。
- 題目歸類不清楚：先分辨問的是價值、人生目標、實際行為還是具體關係期待，避免將同個生活主題誤當同一測量概念。
- 若畫面與文件不同：目前畫面只有示例，此文件為後續內容藍圖；先看實作狀態，不把文件寫入當成已上線功能。
